# Auth API Module\n\nThis module implements authentication endpoints using standardized contracts from the shared contracts package.\n\n## Architecture\n\n### Contracts Used\n- **LoginRequest**: Defines the login request structure\n- **LoginResponse**: Defines the login response with user and tokens\n- **ApiResponse<T>**: Generic wrapper for all API responses\n- **ApiErrorResponse**: Error response format\n\n### Structure\n\n```\nauth/\n├── auth.controller.ts      # Handles HTTP requests\n├── auth.service.ts         # Business logic\n├── auth.module.ts          # Module definition\n├── dtos/\n│   ├── LoginRequest.dto.ts # DTO with validation decorators\n│   └── index.ts\n└── auth.example.ts         # Usage examples\n```\n\n## Login Endpoint\n\n### Request\n\n**POST** `/auth/login`\n\n```json\n{\n  \"email\": \"user@example.com\",\n  \"password\": \"password123\"\n}\n```\n\n### Success Response (200 OK)\n\n```json\n{\n  \"success\": true,\n  \"statusCode\": 200,\n  \"message\": \"Login successful\",\n  \"data\": {\n    \"user\": {\n      \"id\": \"user-1\",\n      \"email\": \"user@example.com\",\n      \"firstName\": \"John\",\n      \"lastName\": \"Doe\",\n      \"createdAt\": \"2024-01-01T00:00:00.000Z\"\n    },\n    \"accessToken\": \"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.access.1704067200000\",\n    \"refreshToken\": \"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.refresh.1704067200000\",\n    \"expiresIn\": 3600\n  },\n  \"timestamp\": \"2024-01-01T00:00:00.000Z\"\n}\n```\n\n### Error Response (400 Bad Request)\n\n**Validation Errors**:\n```json\n{\n  \"success\": false,\n  \"statusCode\": 400,\n  \"message\": \"Validation failed\",\n  \"error\": \"BadRequestException\",\n  \"details\": [\n    {\n      \"field\": \"email\",\n      \"message\": \"Email must be a valid email address\"\n    },\n    {\n      \"field\": \"password\",\n      \"message\": \"Password must be at least 6 characters\"\n    }\n  ],\n  \"timestamp\": \"2024-01-01T00:00:00.000Z\"\n}\n```\n\n### Error Response (401 Unauthorized)\n\n**Invalid Credentials**:\n```json\n{\n  \"success\": false,\n  \"statusCode\": 401,\n  \"message\": \"Invalid email or password\",\n  \"error\": \"UnauthorizedException\",\n  \"timestamp\": \"2024-01-01T00:00:00.000Z\"\n}\n```\n\n## Validation Rules\n\n- **Email**: Must be a valid email address\n- **Password**: Minimum 6 characters\n\n## Test User\n\nFor testing purposes, use:\n- Email: `demo@example.com`\n- Password: `password123`\n\n## Key Features\n\n✅ **Contract-based API**: Uses shared contracts for request/response validation\n✅ **Global Exception Filter**: Standardized error responses\n✅ **Validation**: Input validation with class-validator\n✅ **CORS Enabled**: Cross-origin requests allowed\n✅ **Proper HTTP Status Codes**: Returns appropriate status codes\n✅ **Timestamp**: All responses include ISO timestamp\n\n## Dependencies Required\n\n```bash\nnpm install class-validator class-transformer\n```\n\n## Implementation Notes\n\n1. **Request DTO**: `LoginRequestDto` includes validation decorators that are automatically processed by the ValidationPipe\n2. **Service**: Returns typed `LoginResponse` from the contract\n3. **Controller**: Wraps the response in `ApiResponse<LoginResponse>` for consistency\n4. **Exception Filter**: Automatically catches and formats all errors according to `ApiErrorResponse` format\n\n## Usage Example\n\n```typescript\nimport type { LoginRequest, ApiResponse, LoginResponse } from '@contracts';\n\nconst loginRequest: LoginRequest = {\n  email: 'demo@example.com',\n  password: 'password123',\n};\n\nconst response = await fetch('http://localhost:3000/auth/login', {\n  method: 'POST',\n  headers: { 'Content-Type': 'application/json' },\n  body: JSON.stringify(loginRequest),\n});\n\nconst data: ApiResponse<LoginResponse> = await response.json();\n\nif (data.success) {\n  console.log('User:', data.data?.user);\n  console.log('Token:', data.data?.accessToken);\n}\n```\n"
